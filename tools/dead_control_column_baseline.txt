# --- Confirmed tool false positive: hyphenated column name ---
# teams.sub-group: the bare-array-key regex (`[\s*['"]([a-zA-Z0-9_]+)['"]\s*]`)
# does not include `-` in its character class, so `$row['sub-group']` (a real,
# legitimate read — this column IS used, see Phase 125's CLAUDE.md pitfall
# entry which documents the writer) can never register as a read. Known
# limitation, not fixed here (adding `-` to the class risks matching CSS-class-
# style strings elsewhere); documented in the tool's own docblock.
